# 主题：网络 —— "连接"是一种两端共谋的幻觉

一条脊梁：**网络上不存在"连接"这个实体。** 所谓 TCP 连接，只是通信两端各自在内存里维护的一组状态（序列号、窗口、定时器），靠不断交换的小纸条，维持着"我们俩还连着"的共识。一旦你接受"连接是幻觉、可靠是端上模拟出来的"，从 TIME_WAIT 到队头阻塞到长连接保活，所有怪现象都会瞬间变顺。

本主题用十问，把"字节怎么在不可靠的世界里变成可靠的流"讲到见底。CDN、网关、连接池、TLS——后端日常的网络疑难，全在射程内。

> 顺序读 [深讲十问](./深讲十问.md)。第 6 问会和[并发原理](../并发原理/)的"局部优化组合出错"碰头，第 10 问会和[缓存](../缓存/)、[分布式系统](../分布式系统/)碰头。
