# 主题：分布式系统 —— 没有"现在"的世界

一条脊梁：**你永远不知道对方此刻的状态，只知道"它过去某个时刻说过什么"。**

单机程序里，"现在几点""A 和 B 谁先发生""它是挂了还是只是慢"——这些都是免费的、确定的。一跨网络，它们**全部失效**。分布式系统几乎所有让人头大的难题，都是这个失效的直接推论：时钟、一致性、共识、事务、幂等、锁、脑裂，串起来是同一个故事的不同章节。

本主题用十问把这条脊梁讲到见底。每问都问"为什么必须这样"，都藏一个反直觉的 puzzle，都能回到一手论文 / 可运行的最小推演去验证。

> 顺序读 [深讲十问](./深讲十问.md) 即可。和[并发原理](../并发原理/)主题里的 happens-before 是同一个幽灵，会在第 1 问就碰头。

## 十问索引
1. 跨网络后，"现在"和"先后"为什么同时失效
2. 为什么没有算法能区分"挂了"和"只是慢"（FLP）
3. CAP 为什么不是"三选二"
4. 强一致为什么昂贵到大多数系统付不起
5. 2PC 最致命的失效点在哪一刻
6. 共识为什么难到要诺奖级算法，quorum 为什么是 N/2+1
7. "Exactly-once 投递"为什么是个障眼法
8. "扣款 100 元"怎么幂等
9. 分布式锁为什么没 fencing token 就不安全
10. 脑裂为什么最终都回到"多数派"
