# 主题：可靠性工程 —— 失败是设计出来的，不是消除的

一条脊梁：**可靠系统不是"不会失败的系统"，而是"想清楚了每种失败发生后怎么办的系统"。** 最反直觉的是——那些用来提升可靠性的手段（重试、超时、冗余、健康检查）本身就是最危险的放大器，能把一次小抖动放大成一场雪崩。这条脊梁是[大模型](../大模型/)主题"可靠性不来自模型、来自外面的约束"在系统层的投影：可靠从来不是某个零件自带的属性，是你在系统层主动设计、并验证过的结果。

本主题用十问，把"系统怎么在零件必然会坏的前提下依然可用"讲到见底。重试、超时、熔断、背压、降级、混沌——SRE 的核心武器库全在这里。

> 顺序读 [深讲十问](./深讲十问.md)。第 4 问会和[并发原理](../并发原理/)的有界 channel、[网络](../网络/)的 TCP 流控碰头；第 6、10 问会和[元认知](../../)的"感觉良好≠做对了"碰头。
