# 主题：缓存 —— 用"可能过期的副本"换速度

一条脊梁：**缓存的本质，是持有一份可能已经过时的副本来换速度。** 所以缓存的一切难题，都是同一个问题的变体：**这份副本什么时候、凭什么、由谁判定它过期了？** "缓存失效是计算机科学两大难事之一"不是段子——因为它逼你在"新鲜度、可用性、一致性"这个不可能三角里，当场选边站。

本主题用十问，把"为什么加缓存常常是把一个问题换成两个问题"讲到见底。穿透击穿雪崩、一致性、多级缓存、CDN、Redis——后端日常的缓存疑难全在射程内。直接延续作者的 singleflight demo 和 CDN 经验。

> 顺序读 [深讲十问](./深讲十问.md)。第 1、4、7 问连到[分布式系统](../分布式系统/)的一致性；第 6 问连到[网络](../网络/)的 DNS/CDN；第 10 问连到[存储引擎](../存储引擎/)的 WAL。
