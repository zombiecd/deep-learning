# 主题：安全思维 —— 信任边界与"一切输入皆敌"

一条脊梁：**安全不是一个功能模块，是一种看系统的视角——在哪里，数据从"我控制的"变成"别人能影响的"，那条线就是信任边界，而所有漏洞都长在没被认出来的信任边界上。** 一旦你养成"这个数据是谁能控制的"这个条件反射，注入、越权、SSRF 这些看似无关的漏洞，会显出同一个骨架。

这正是 AI 写代码时最系统性的盲区——它擅长写出"功能正确、看起来对"的代码，却对信任边界、时序侧信道、最小权限这些"非功能的正确性"频繁失明。所以安全思维是[AI 时代工程师](../AI时代工程师/)那个"保证者"最该握紧的判断之一：**这恰恰是你能接住 AI、而 AI 接不住自己的地方。**
