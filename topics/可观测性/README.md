# 主题：可观测性的认识论 —— 在不能全量观测的约束下重建真相

一条脊梁：**你永远无法完整观测一个生产系统——全量记录的成本会超过系统本身。** 所以可观测性的本质不是"记录一切"，而是一个**统计推断问题**：用有限的、有偏的、被采样的信号，去重建系统的真实状态。一旦你意识到"你盯着的监控大盘，是一个被各种偏差扭曲的影子"，你才算真正会看监控。

本主题用十问，把"怎么知道一个你看不进去内部的系统此刻到底怎么了"讲到见底。指标、日志、链路、采样、基数、尾延迟——这些日常运维词背后，全是认识论的取舍。直接呼应作者的 CDN 日志 / ClickHouse 经验。
