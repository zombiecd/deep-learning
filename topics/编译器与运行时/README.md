# 主题：编译器与运行时 —— 你写的代码不是真正运行的代码

一条脊梁：**你写的源码，只是给优化器的一份"意图说明书"，不是执行脚本。** 编译器和运行时会内联、逃逸、消除、重排、回收——等真正跑起来时，和你写的那一行常常对不上。[AI 时代工程师](../AI时代工程师/)那篇讲的"机械同理心"，核心就是看穿这层"源码 → 实际执行"的映射；看不穿，你对性能的一切判断都是猜的。

本主题用十问，把"从你按下保存到 CPU 真正执行，中间发生了什么"讲到见底。Go 当主镜头（逃逸分析、GC、内联、栈扩容），关键处对照 C++/Rust/JVM。直接延续作者并发 lab 里的反汇编经验。

> 顺序读 [深讲十问](./深讲十问.md)。第 3 问的 GC 写屏障、第 7 问的伪共享/内存布局，直通[并发原理](../并发原理/)；多问都能用 `go build -gcflags=-m` 和反汇编一手验证。
