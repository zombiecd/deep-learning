# 主题：LLM 应用的系统工程 —— 在概率地基上盖确定的房子

一条脊梁：**把一个会编造、不确定、有损的模型，工程化成一个敢交付的系统——靠的从来不是模型本身变可靠，而是你在它外面盖的那一圈确定的工程（接地、约束、验证、反馈）。**

这是[大模型](../大模型/)主题"靠谱从哪来"的落地版，也是后端工程师的判断力在 AI 时代**最值钱的变现处**：你比模型更懂系统。这个主题刻意放在最后——它是整张网的**收口**：前九个主题练出的系统判断力（一致性、可靠性、缓存、性能、尤其是安全的信任边界），会在这里**全部回来**，因为"在一个概率系统外面盖确定工程"，恰恰是把后端的全部硬功夫，用到 AI 这个新地基上。

> 顺序读 [深讲十问](./深讲十问.md)。它密集呼应大模型主题里你已成文的概念（误差复利、外部接地、两层幻觉、收尾权），并在第 6、10 问与[安全思维](../安全思维/)的信任边界、注入合流，收口全部 100 问。
